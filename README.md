# MIUMEOSHOP — Neon Pink

## Cấu trúc
- `index.html`: website
- `images/logo.png`: logo MIUMEOSHOP đã thiết kế
- `images/products/`: ảnh sản phẩm
- `music/shop.mp3`: nhạc nền

## Tự nhận ảnh sản phẩm
Tên ảnh phải trùng slug trong `index.html`, ví dụ:
`images/products/ao-thun-basic.webp`

Web tự thử `.jpg`, `.jpeg`, `.webp`, `.png`, nên không cần sửa HTML.

## Nhạc
Đặt file MP3 tại `music/shop.mp3`. Trình duyệt iPhone có thể chặn autoplay; web sẽ tự thử phát và phát ngay sau lần chạm đầu tiên.
