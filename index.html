Code chạy chậm hơn 20-50% và file nặng hơn nhiều — chỉ nên dùng cho file JS thật sự quan trọng, không dùng cho thư viện bên thứ ba. "Khóa theo domain" làm code chỉ chạy đúng trên domain bạn nhập, báo lỗi nếu bị copy sang site khác — nhớ nhập đúng domain, nếu không code sẽ không chạy được ngay cả trên site của bạn.

Với CSS thì trình duyệt vẫn phải đọc được cấu trúc nên chỉ thu gọn được đến mức đó. Với HTML giờ có 2 lựa chọn: "Thu gọn" (xóa comment/khoảng trắng, View Source vẫn đọc được nội dung) hoặc "Mã hóa qua JS" (HTML được mã hóa base64 rồi nhét vào 1 đoạn JS obfuscate mức tối đa — khi tải trang, JS tự giải mã và ghi ra; bấm View Source lúc này chỉ thấy 1 script rối, không còn thấy HTML thật). Tab "Cả 3 (gộp trang)" làm cả 2 lớp cùng lúc: JS bạn dán được obfuscate riêng trước (control flow flattening, mã hóa chuỗi...), CSS được thu gọn, sau đó cả trang (HTML+CSS+JS đã obfuscate) được gộp thành 1 file rồi mã hóa thêm 1 lớp qua JS decoder — ra đúng 1 file .html duy nhất, mở lên chạy y hệt trang gốc nhưng View Source chỉ thấy 1 script rối bời. Lưu ý: cách này không giấu được với tab Elements của DevTools (luôn hiện DOM sau khi render), và Google/công cụ tìm kiếm sẽ khó đọc nội dung trang — đừng dùng cho trang sản phẩm cần lên SEO, chỉ nên dùng cho trang phụ không cần index (vd: trang báo giá CTV nội bộ).
