Mạnh hơn bản trước ở JS: control flow flattening 100%, dead code injection, chuỗi mã hóa RC4 + xoay vòng + chia nhỏ từng đoạn 3 ký tự + bọc unicode escape, 5 lớp string-array wrapper lồng nhau, ép số thành biểu thức, chống mở DevTools, tự vệ nếu code bị format lại. Code chạy chậm hơn 20-50% và file nặng hơn nhiều — chỉ nên dùng cho file JS thật sự quan trọng, không dùng cho thư viện bên thứ ba. "Khóa theo domain" làm code chỉ chạy đúng trên domain bạn nhập, báo lỗi nếu bị copy sang site khác — nhớ nhập đúng domain, nếu không code sẽ không chạy được ngay cả trên site của bạn. Với CSS/HTML, trình duyệt vẫn phải đọc được cấu trúc nên chỉ thu gọn được đến mức này, không giấu nội dung. Tệp tải xuống có đuôi .txt do giới hạn nền tảng — đổi lại thành .js/.css/.html sau khi tải.
